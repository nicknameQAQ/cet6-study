# 六级备考资料与统计复算

基于六级真题材料整理的1500核心词汇、100条高频短语、听力阅读和写作翻译学习册，以及语料统计、出处记录和复算脚本；另附按考试日期整理的四级、六级真题与解析 PDF。

## 从哪里开始

进入 [学习资料](六级备考成果/学习资料/)，选择核心词汇、短语或专项册。建议下载整个文件夹，用支持书签、搜索和跨文件跳转的 PDF 阅读器打开，并保持原文件名和同目录关系。

这是公开整理版，包含通用学习资料、脚本和统计数据。个人情况与定制学习计划、原使用指南、历史版本、打包文件、核验图片、依赖库和缓存不包含在仓库中。已收录原始真题与解析 PDF，听力音频和网页校对缓存未上传。

## 脚本与复算

详细流程见 [复算说明](六级备考成果/复算说明.md)。只阅读现成 PDF 时，无需安装 Python。

重新生成资料需要 Python 3，以及 `reportlab`、`PyMuPDF`、`Pillow`、`nltk`、`beautifulsoup4`、`rapidfuzz` 等依赖；OCR 步骤还涉及 Windows OCR 或其他 OCR 工具。脚本依赖现有统计数据、词典与语言模型，不能仅凭安装 Python 库完成全量复算。

为减小仓库体积，大型数据文件以 `.gz` 保存。复算前在仓库根目录解压一次：

```powershell
python -c "from pathlib import Path; import gzip; [(p.with_suffix('').write_bytes(gzip.decompress(p.read_bytes()))) for p in Path('六级备考成果/数据').glob('*.gz')]"
```

字典与 NLTK 模型需根据脚本要求自行安装。原始真题与解析 PDF 已按原相对路径收录；全量复算仍需按来源记录补齐网页参考文本、语言模型及其他依赖环境。

在仓库根目录，按顺序执行当前版本修订流程：

```powershell
python "六级备考成果/脚本/enrich_vocabulary.py"
python "六级备考成果/脚本/revise_vocabulary_pdfs.py"
python "六级备考成果/脚本/revise_writing_translation.py"
python "六级备考成果/脚本/verify_vocabulary_revision.py"
```

生成后应检查核验结果并逐页复核 PDF。仓库中的指南生成代码已改为通用说明。

排版脚本使用 Windows 宋体、黑体和 Arial 路径。迁移到其他系统时，需要调整字体路径；依赖库应重新安装。新增真题时还需更新资料清单、校对原文和套号，再按复算说明执行完整流程。

## 数据说明与来源

词频沿用语料的词形归并计数，未按每个词义拆分；总频次不等于某个例句义项的出现次数。编码残缺的 15 条原句暂不计入可靠词频，原文与出处保留在待核对清单中。自动检查与版面抽查不代表所有释义均经语言教师逐条审定。

资料来源与处理记录见 `六级备考成果/数据/资料清单.json`、`补充资料来源.json`、`校对参考来源.json` 等文件。词典参考包含 [ECDICT](https://github.com/skywind3000/ECDICT) 与 WordNet；第三方试题、解析、音频和词典的权利与许可归各自权利人，具体来源以记录为准。
