# 六级资料复算说明

本次版本：1500个主词条、15卷词汇册、100组写作替换指导、32道替换练习。

本公开版不附个人指南、原始试卷、打包文件和依赖库；大型数据先按 README 解压。复算时需自行补齐脚本所需来源与模型。

## 原始工作目录约定

将统计数据包解压到原“英语”文件夹，压缩包内已保留“六级备考成果/数据”“六级备考成果/脚本”和“补充资料_2026年6月”目录。原2021—2025试卷目录继续保留。完整资料包中的“学习资料”放到“六级备考成果/学习资料”中。不要修改原文册与索引册的文件名，否则跨文件跳转失效。

## 环境

脚本使用Python 3、reportlab、PyMuPDF、Pillow、nltk、beautifulsoup4、rapidfuzz等库。本机已有环境和“数据/python_libs”；迁移电脑时需重新安装依赖，不应复制本机二进制库。排版使用Windows宋体、黑体和Arial，其他系统需替换脚本中的字体路径。

数据包保留本次使用的中英词典、英音词表、WordNet及英文词性模型。音标来源与编辑补充记录见词条的ipa_source字段；资料来源见资料清单和补充资料来源。现有双语例句由完整原段落及对应参考译文组成。

## 只重建本次修订

在原“英语”文件夹中，按以下顺序执行，每一步成功后再继续：

1. `python 六级备考成果/脚本/enrich_vocabulary.py`：应用词性、语境义、音标、近义辨析与词族编辑层。
2. `python 六级备考成果/脚本/revise_vocabulary_pdfs.py`：重建15卷及指南，更新跨卷页码。
3. `python 六级备考成果/脚本/revise_writing_translation.py`：重建写作翻译册，包括100组指导和32道练习。
4. `python 六级备考成果/脚本/verify_vocabulary_revision.py`：逐页检查新版PDF；比对1500条双语原文、出处页与统计值。
5. 查看“六级备考成果/核验/1500词修订”中的渲染图，复核版面。只有确认通过后，才将验收报告对应的visual_review记为passed，保留实际检查方法和范围。
6. `python 六级备考成果/脚本/package_results.py`：核对PDF哈希、生成三个压缩包并验证压缩包完整性。

`prepare_vocabulary_revision.py`负责从已清洗语料重新选取1000个新增词，保留原500词；日常编辑时不必重选。修改选词逻辑、添加新真题或更换例句后，要重新检查编辑辨析是否适用于新语境。

## 全量更新

原始流程包括提取/OCR、校对、语料去重、统计、例句来源定位和PDF生成。已有`build_learning.py`、`build_pdfs.py`、`qa_and_package.py`已接入1500词修订，避免完整生成时退回旧500词版本。新增试卷仍需先补齐资料清单、校对原文及套号，不能只把文件放进目录便认为已统计。

## 本次检查的含义

数量、唯一性、词频一致性、双语例句与来源页文本、PDF缺字/越界/跳转进行自动逐条或逐页检查，并对版面和多音词、词性冲突做人工抽查与修正。近义辨析包含编辑说明与WordNet义项对照；没有合适单词近义词的条目使用明确标注的释义转述，不能机械代入原句。未确认的词族与形近关系不强行补齐。自动比对通过不等于所有释义均已由语言教师逐条审定。

沿用语料的词形归并频次，并未按每个词义重新分拆计数；标题、机构名称和专名中的同形词也可能在完整出处索引中。因此总次数不能理解成所选例句义项的出现次数。主词例句按可学习的实际语境解释，人名本身不充当其同形普通词的释义依据。
